About this
Absolute units follow the W3C CSS Values spec: 1in = 96px = 72pt = 6pc = 2.54cm, so 12pt = 16px. rem and em use your base size here. The scale is size = base x ratio^step, with exact ratios (a perfect fourth is 4/3, so step 2 at 16px is 28.44, where some tools using 1.333 show 28.43). Runs in your browser.
